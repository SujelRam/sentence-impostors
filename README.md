# 🎭 Sentence Impostors

Sentence Impostors is an interactive web-based game that challenges players to identify fake or misleading sentences among a set of real ones. The project helps improve critical thinking, language comprehension, and attention to detail through engaging gameplay.

Whether used for fun, education, or language-learning practice, Sentence Impostors provides an exciting way to test your ability to spot the odd sentence out.

---

## 🚀 Features

- Interactive sentence-based gameplay
- Identify the impostor sentence from multiple options
- Score tracking system
- User-friendly interface
- Instant feedback on answers
- Lightweight and responsive design
- Suitable for learning and entertainment

---

## 🛠️ Technologies Used

- JavaScript
- HTML5
- CSS3
- Browser-based UI

---

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/SujelRam/sentence-impostors.git
cd sentence-impostors
```

### Open the Project

Simply open the `index.html` file in your browser.

Or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

---

## ▶️ Usage

1. Launch the application.
2. Read the displayed sentences carefully.
3. Identify the sentence that does not belong to the group.
4. Submit your answer.
5. Receive instant feedback and continue to the next round.

---

## 📊 Sample Gameplay

```text
Choose the Impostor Sentence:

1. The sun rises in the east.
2. Water freezes at 0°C.
3. Fish can breathe underwater.
4. Trees can walk from one city to another.

Correct Answer:
4. Trees can walk from one city to another.
```
